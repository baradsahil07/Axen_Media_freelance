# Axen Media — High-End Video Editing Agency Website

A complete, production-quality, animated marketing website built for **Axen Media** (a premier video editing agency). Built from scratch matching the official Figma designs and screenshots with pixel precision, featuring fluid scroll-driven animations, 3D interactive components, video carousels, and responsive mobile-first architecture.

---

## ⚡ Tech Stack

- **React 18** + **Vite**: Modern functional components, custom hooks, and route-level code splitting.
- **Tailwind CSS**: Strict centralized design token system (`tailwind.config.js`), customized colors, typography, and container scales.
- **Framer Motion**: UI-level motion (mount/unmount, hover/tap, tabs, accordion, modal lightboxes, shared-layout animations, and route transitions).
- **GSAP + ScrollTrigger + @gsap/react (`useGSAP`)**: Scroll-driven and timeline motion (line-mask text reveals, parallax scrub, velocity marquees, stat count-ups, drawing connector lines).
- **Lenis**: Smooth inertial scroll engine synchronized frame-by-frame with GSAP's `ScrollTrigger.update`.
- **react-router-dom (v6)**: Declarative multi-page routing (`/`, `/portfolio`, `/contact`, `/get-hired`).
- **react-hook-form**: Controlled contact form with validation, animated inline errors, and submission states.
- **lucide-react**: Lightweight SVG icons.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```

### 5. Run Linter
```bash
npm run lint
```
